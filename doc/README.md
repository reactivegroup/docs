# 技术资料目录

`doc/` 保存 Reactive 技术兴趣小组的 SIG 学习资料、技术路线图和可编辑源文件。目录名是历史路径，为保持 [SIG 小组文档](../SIG_GROUP.md) 中的链接稳定，暂不改名。

| 目录 | 主题 | 内容 |
| --- | --- | --- |
| [`Reactive/`](./Reactive/) | 反应式编程 | [SIG 资料](./Reactive/SIG_MATERIAL.md)、技术路线图和 XMind 源文件 |
| [`RPC/`](./RPC/) | RPC 与中间件 | [SIG 资料](./RPC/SIG_MATERIAL.md)、技术路线图和 XMind 源文件 |
| [`CloudNative/`](./CloudNative/) | 云原生中间件 | [SIG 资料](./CloudNative/SIG_MATERIAL.md)、技术路线图和 XMind 源文件 |
| [`技术路线/`](./%E6%8A%80%E6%9C%AF%E8%B7%AF%E7%BA%BF/) | SIG 总体划分 | 总览图和演示文稿源文件 |

维护约定：

- Markdown 用于可搜索的资料索引和说明。
- PNG 用于仓库内预览，XMind 或 PPTX 保留可编辑源文件。
- 更换图片或路线文件时，同步检查 `SIG_GROUP.md` 中的引用。
- 如需重命名 `doc/`，先提供目标路径、链接迁移表和兼容说明。
